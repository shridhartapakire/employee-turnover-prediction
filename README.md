# Employee Turnover Prediction System

## Project Overview

This project predicts whether an employee is likely to leave an organization using Machine Learning.

The application will be developed using Django and will provide a user-friendly interface for uploading employee datasets, generating predictions, visualizing insights, and displaying analytical reports.

This project is being rebuilt completely from scratch as a learning project.

---

## Objectives

- Learn Django professionally
- Understand Machine Learning integration
- Build a production-style web application
- Learn project architecture
- Maintain meaningful GitHub history
- Improve software engineering skills
